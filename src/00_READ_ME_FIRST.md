## 🆘 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Port 5173 in use | Kill process or use different port |
| Module not found | Run `npm install` again |
| Blank page | Hard refresh: `Ctrl+Shift+R` |
| Chat not working | Make sure you're logged in |
| Notifications not showing | Refresh page |
| Styling looks wrong | Clear cache, hard refresh |

**For more help:** See SETUP_GUIDE.md - Troubleshooting section
