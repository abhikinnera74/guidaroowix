## 🚀 Super Quick Start (Copy & Paste)

### 1. Open Terminal in Project Folder
```bash
cd path/to/guidaroo
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```

### 4. Open Browser
```
http://localhost:5173/
```

### 5. Start Using!
- Click "Tourist Login"
- Browse guides
- Book a guide
- Chat with guide

## 🆘 Troubleshooting

### Port Already in Use?
```bash
# Windows
taskkill /PID <PID> /F

# Mac/Linux
kill -9 <PID>
```

### Module Not Found?
```bash
npm install
```

### Blank Page?
- Press `Ctrl+Shift+R` (hard refresh)
- Clear browser cache

### Chat Not Working?
- Make sure you're logged in
- Make sure you have a booking
- Check browser console (F12)
