## 📌 What's New?

Your guide dashboard now has **4 powerful tabs** for managing every aspect of the guide business:

### 📋 Overview Tab
- Pending booking requests
- Active bookings with maps
- Recent notifications
- Quick statistics

### 📅 Availability Tab
- Interactive calendar
- Add/remove time slots
- Visual indicators
- Easy management

### 💰 Earnings Tab
- Total earnings tracking
- Period-based filtering
- Payout requests
- Financial analytics

### ⭐ Reviews Tab
- Average rating display
- Rating distribution
- Individual reviews
- Sorted by recent

### 🔔 Bonus: Notifications
- Real-time notification bell
- Unread count badge
- Dropdown list
- Mark as read/delete
