## User Journey

```
1. SIGN IN
   ↓
2. CHECK PROFILE STATUS
   ├─ If new → Show onboarding
   └─ If existing → Show dashboard
   ↓
3. DASHBOARD OVERVIEW
   ├─ See pending bookings
   ├─ See active bookings
   ├─ See notifications
   └─ See quick stats
   ↓
4. MANAGE BOOKINGS
   ├─ Accept/decline requests
   ├─ View booking details
   └─ Navigate to tourist
   ↓
5. MANAGE AVAILABILITY
   ├─ Open calendar
   ├─ Add/remove slots
   └─ Save changes
   ↓
6. TRACK EARNINGS
   ├─ View total earnings
   ├─ Filter by period
   └─ Request payout
   ↓
7. VIEW REVIEWS
   ├─ See average rating
   ├─ Read individual reviews
   └─ Track feedback
   ↓
8. MANAGE NOTIFICATIONS
   ├─ Check bell icon
   ├─ Mark as read
   └─ Delete old ones
```
