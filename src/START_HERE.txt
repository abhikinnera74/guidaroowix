================================================================================
                      🆘 TROUBLESHOOTING
================================================================================

Port Already in Use?
  Windows: taskkill /PID <PID> /F
  Mac/Linux: kill -9 <PID>

Module Not Found?
  npm install

Blank Page?
  Press Ctrl+Shift+R (hard refresh)

Chat Not Working?
  - Make sure you're logged in
  - Make sure you have a booking
  - Check browser console (F12)

For more help:
  → See SETUP_GUIDE.md - Troubleshooting section
